Bitbucket PR for Jira Options

Domains

Host name of your Jira site, without https:// or a path.

Host name of your Bitbucket server, without https:// or a path.

When you save, Chrome asks for permission to access these two sites. Reload open Jira and Bitbucket tabs after saving.

Pull request title search

Repositories whose pull request titles are searched for the Jira key, when "Include search PR Text" is enabled in the popup. One PROJECT/repository per line.

Bitbucket authentication

Optional. Leave empty to use your Bitbucket session cookie from this browser instead.
