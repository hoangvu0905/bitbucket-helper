Jira / Bitbucket domains and the Bitbucket token are set in the extension options.

When enabled, also searches for pull requests by Jira key in the PR titles of the repositories set in the extension options.

When enabled, automatically fetches pull request data when a Jira page loads.

When enabled, replaces Jira issue links on Bitbucket pages with Atlassian Jira links.

How to use:

  1. Open a Jira issue page on your configured Jira domain
  2. Click the "Bitbucket" button to view related pull requests
  3. The button will turn green when PRs are found
